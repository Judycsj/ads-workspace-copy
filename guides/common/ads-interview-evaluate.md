# 面试评估助手（ads-interview-evaluate）使用指南

> **语言**：[中文](ads-interview-evaluate.zh-CN.md)

基于面试 Q&A 记录，生成结构化评分和面评。支持单轮评估（回写到 interview-record.md）和多轮综合评估（输出 interview-note.md）。

**唤醒词**：「面试评估」、「面试打分」、「面评」、「生成面评」、「面试结论」、「interview evaluate」、「interview note」

## 基本用法

### 1. 单轮评估（填写初面/复面结论）

面试结束后，请 AI 辅助生成面试结论：

```
帮我评估初面结果，interview-record 在：
docs/team/00.paid-ads-dev/19.interview-list/260622-749439999/interview-record.md
§3.2 已经填好了面试记录
```

AI 会：
1. 读取 §3.2 中的 Q&A 记录和观察备注
2. 逐维度评分（A1-A3 + T1-T6，每个分数关联证据）
3. 生成 §3.3 初面面试结论
4. 展示结果，等面试官校准确认后回写

### 2. 多轮综合评估（生成 interview-note.md）

初面和复面都结束后，生成综合面评：

```
帮我生成综合面评，初面和复面结论都在 interview-record.md 里了
```

AI 会：
1. 读取 §3.3 初面结论 + §4.3 复面结论
2. 汇总初面+复面的维度评分，生成综合分
3. 输出 `interview-note.md`（可直接用于录入 Moka）

### 3. 直接输入 Q&A 记录

不依赖 interview-record.md，直接输入面试记录：

```
帮我评估这次面试，Algo 角色，目标 EE：
Q1: 日常 AI 使用 -> 候选人说每天用 Claude Code 写代码...
Q2: 项目深挖 -> 候选人说...
```

## 输出示例

### 单轮结论（§3.3 / §4.3）

```markdown
### 3.3 初面面试结论 [会后]

- 整体印象: 项目深度扎实，AI 使用停留在 L1
- 建议结论: 待定，评分 3.5/5
- 核心理由: 技术深度达到 EE，但 AI-native 能力不足
- 需要复面重点验证: T1 AI-Native（是否有工具链建设能力）
- 各维度快速评价:
  - A2 算法建模: 4 — MTL/MMOE 选型有说服力
  - AI-Native (T1): 3 — 日常用 AI 写代码但无 Agent/Skill 沉淀
  - 项目深度 (T2): 4 — 能讲清 why 和 alternative，真实参与度高
```

### 综合面评（interview-note.md）

包含初面+复面双列评分对比表、综合评分、优势/风险、后续建议、招聘理由（可选）。

---

## 校准清单

评估完成后，AI 会展示以下校准项：

- [ ] 面评是否过度美化候选人？
- [ ] 是否把"候选人说过"误判为"候选人做过"？
- [ ] 是否对目标职级使用了正确标准？
- [ ] 是否遗漏了关键负向信号？
- [ ] 各维度评分是否与证据一致？
- [ ] 初面和复面结论是否一致？

## 常见问题

**Q: 初面面试官和复面面试官可以各自独立评估吗？**
A: 可以。每轮面试官各自填写 §3.3 / §4.3，最后由任一方触发综合评估。

**Q: SEE/PE 级别有什么特殊要求？**
A: 必须评估 T6 管理能力。T6 <= 2 分为否决项（Rule E8）。

**Q: 可以按不同职级重新评估吗？**
A: 可以，但必须单独成段标注"如果按 {其他职级} 评价"（Rule E3），主评结论不变。

**Q: 招聘理由补充什么时候用？**
A: 仅在结论为"通过"时可选使用，需要回答 5 个问题（能力缺口/不可替代性/匹配点/能力建设/时间窗口）。

**Q: 评分怎么锚定？**
A: 专业维度：3 = 目标职级 Average，5 = Outstanding。团队维度：参考 02-core-concepts.md 信号层级。
