# 面试准备助手（ads-interview-prepare）使用指南

> **语言**：[中文](ads-interview-prepare.zh-CN.md)

基于候选人简历和目标职级，生成统一候选题池 + 初面/复面终版模板。面试官从题池中选题填入终版方案，面试后填写结论。

**唤醒词**：「面试准备」、「面试方案」、「简历分析」、「出面试题」、「生成面试方案」、「interview prepare」、「interview plan」

## 基本用法

### 1. 生成面试方案

提供简历 + Moka 链接 + 角色通道 + 目标职级：

```
帮我生成面试方案，候选人简历在这里（粘贴/文件路径），
Moka: https://app.mokahr.com/interviews/overview/749439999
角色 Algo，目标职级 SEE
```

AI 会按步骤生成：
1. §1 候选人能力画像（简历摘要 + 能力初评 + 风险点）
2. §2 候选题列表（深挖项目 + AI 实操题 + 软素质题 + 管理题）
3. §3 初面终版空模板 + 校准清单
4. §4 复面终版空模板 + 校准清单

输出到 `docs/team/00.paid-ads-dev/19.interview-list/{YYMMDD}-{candidateID}/interview-record.md`

### 2. 填写初面终版方案

```
帮我填写初面方案，我选：
- 项目深挖：2.1.1 项目一的 Q1、Q3、Q5
- AI 实操题：2.2.1 方向一场景 A
- 其他问题：2.3 的业务数据敏感度 + Q2 离职动因
```

AI 从 §2 题池中提取所选题目，填入 §3.2 终版方案。

### 3. 填写复面终版方案

```
帮我填写复面方案，参考初面结论。我选：
- 项目深挖：2.1.2 项目二的 Q1、Q3
- AI 实操题：2.2.3 方向三场景 A
- 管理能力：2.4 的 Q1 目标拆解 + Q3 过程管理
```

如果选择的题目已在初面使用，AI 会标注 `⚠️ 初面已考察` 并建议替换。

### 4. 面试后填写结论

```
帮我填写初面结论，整体感觉不错，项目深度很好但 AI 使用一般
```

AI 辅助生成 §3.3 初面面试结论（维度评分 + 建议结论 + 核心理由）。

## 输出文件结构

```
§1 候选人能力画像          ← AI 自动
§2 候选题列表              ← AI 自动（统一题池）
§3 初面方案               ← 初面面试官填写
  §3.1 校准清单
  §3.2 终版方案（[会前] + [会中]）
  §3.3 初面结论（[会后]）
§4 复面方案               ← 复面面试官填写
  §4.1 校准清单
  §4.2 终版方案（[会前] + [会中]）
  §4.3 复面结论（[会后]）
```

## 隐私规则

- **禁止使用候选人真实姓名**，全程 `候选人-{candidateID}`
- 候选人 ID 从 Moka 链接 `/overview/{candidateID}` 提取
- 写入前自动扫描检查

## 常见问题

**Q: 没有 Moka 链接怎么办？**
A: 可以直接提供候选人 ID，或使用 `unknown` 后续补充。

**Q: 只做一轮面试可以吗？**
A: 可以，指定"面试轮次 1 轮"，只生成 §3 初面方案。

**Q: 面试官可以自定义题目吗？**
A: 可以，§3.2/§4.2 终版方案中的题目可以从 §2 选取，也可以完全自定义。

**Q: AI 实操题是必考的吗？**
A: 是的，初面和复面各至少选一个方向（方向一/二/三）。补充问答题为可选。

**Q: 业务数据敏感度是必考的吗？**
A: 强烈建议必考（放在 §2.3 其他问题的第一项），但面试官可酌情调整。
