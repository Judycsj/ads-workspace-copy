## 基本用法

### 实时模式（面试中）

面试过程中，逐条输入候选人回答：

```
候选人说他日常用 Copilot 写代码，主要是自动补全，没有用过 Agent 或知识库
```

AI 立即输出：
- **信号识别**：`[T1-AI-Native] 负向: "主要是自动补全，没用过 Agent" -> AI 使用停留在 L0-L1`
- **追问建议**：1-2 个针对性追问
- **维度覆盖进度**：哪些维度已覆盖/待深挖/未触及

继续输入下一条回答，AI 持续追踪进度。

### 批量模式（面试后）

面试结束后，输入完整 Q&A 记录或录音转写：

```
帮我分析这份面试记录：
Q1: 日常 AI 使用 -> 候选人说...
Q2: 项目概述 -> 候选人说...
...
```

AI 输出完整分析：逐题信号标记 + 维度覆盖度检查 + 风险汇总 + 下一轮建议。

### 结合 interview-record.md

```
加载这个候选人的面试方案：docs/team/00.paid-ads-dev/19.interview-list/260622-749439999/interview-record.md
我现在开始初面，实时模式
```

AI 读取方案后理解考察目标，追问建议更有针对性。

## 包装识别

AI 自动检测以下模式并生成验证性追问：

| 候选人回答模式 | AI 自动追问方向 |
| --- | --- |
| 只讲收益不讲实现 | "具体的模型结构/代码是怎样的？" |
| 只讲方案不讲问题 | "过程中遇到过什么困难？" |
| "我们做了..." | "你个人负责哪部分？" |
| 收益数字异常 | "这个收益怎么归因的？" |
| 回答过于流畅像背诵 | 换角度追问同一个点 |

## 记录回写

分析结果可以回写到 `interview-record.md` 的终版方案中：

```
把刚才的追问和回答要点回写到初面方案 §3.2
```

AI 会将内容填入对应的 `[会中]` 字段。**回写前会确认**，不自动回写。

## 常见问题

**Q: 面试中来不及输入完整回答怎么办？**
A: 输入关键词或要点即可，如"候选人说用 AI 写 SQL，没做过 Agent"。

**Q: AI 会直接给"通过/不通过"判断吗？**
A: 不会。AI 只提供信号标记和追问建议，判断权属于面试官（Rule C3）。

**Q: 可以在面试后再用批量模式补充分析吗？**
A: 可以，两种模式可以混合使用。
