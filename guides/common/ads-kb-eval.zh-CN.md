## 双模式架构

技能运行分为两种模式，在 Step 0（模式判定）阶段确定：

### 模式 A: 新增问题

**触发条件**：用户提供了新问题（单个问题、Markdown 列表或文件路径）。

**流程**：输入解析 → Step 1 预处理（去重、范围检查、分类） → Step 2 路由与评分 → Step 3 写入结果

- 新问题分配永久唯一 QID（格式：`YYYYMMDDHHMMSS`）
- 与 `questions-list.md` 中已有问题去重
- 范围检查检测 scope 过大的问题，交互式拆分
- 分类为 kb / 指标查询 / task / 无效问题（仅 kb 和指标查询进入评分）

### 模式 B: 模块评测

**触发条件**：用户指定了模块名（如 "评估 2.1 召回"），或不带问题直接调用 `/ads-kb-eval`。

**流程**：模块选择器（交互式） → 提取已有问题 → Step 2 重新评分 → Step 3 覆盖更新结果

- 跳过 Step 1 预处理
- 保留原有 QID 和路由信息
- 重新读取 KB 文件最新内容并更新评分
- 三级交互选择器：Chapter → 子模块 → 细分（问题数 > 50 时）

---

## 问题分类（仅模式 A）

| 类别 | 定义 | 处理方式 |
|------|------|---------|
| **kb**（知识型） | 概念、原理、架构、流程等可从文档回答的问题 | 路由 + 评分 |
| **指标查询** | 问动态变化的具体指标数值，答案随时间变化 | 路由 + 按双维度标准评分 |
| **task**（任务型） | 需要执行操作：生成 SQL/报告、跑实验等 | 匹配执行技能，跳过评分 |
| **无效问题** | 表述不清、缺少上下文、无法判断意图 | 标记原因，跳过评分 |

## 使用方法

### 模式 A: 从问题文件批量评测

> "/ads-kb-eval docs/common/question-list.md"

读取所有问题 → 去重 → 范围检查 → 分类 → 路由 → 逐题评分 → 写入结果。

### 模式 A: 单题评测

> "评测 KB：召回双塔模型的训练范式是什么？"

路由到相关召回文件，评分覆盖情况，写入结果。

### 模式 B: 交互式模块选择

> "/ads-kb-eval 评测模块" 或 "/ads-kb-eval"（不带问题）

列出全部模块及问题数量和平均分，用户通过交互菜单选择：
1. **第一级**：选 Chapter（Chapter 1-2 / Chapter 3-4 / Chapter 5-6）
2. **第二级**：选 Chapter 下的子模块
3. **第三级**（可选）：当子模块问题数 > 50 时可进一步细分

### 模式 B: 直接指定模块

> "评估 Chapter1 核心知识 - 2.1 召回"

直接匹配到 §2.1，跳过交互选择器。提取已有问题并重新评分。

## 输出

结果写入 **`docs/common/ops-log/questions/questions-list.md`**（及其 `zh-CN` 版本），按 KB 文件展开，遵循 `index-synthesis.zh-CN.md` 章节结构。写入后 `scripts/refresh_summary.py` 自动刷新统计表。历史评分变化通过 git history 追溯。

表格包含 9 列：`QID | 问题/Question | 类别/Type | 理由/Reason | 主路由文件/Primary File | 辅助路由/Secondary Files | 评分/Score | 低分理由/Low Score Reason | 备注/Note`。非 5/5 的行备注列标记为 `待处理`。

## 评分标准

### KB 类（通用评分）

| 分数 | 定义 |
|------|------|
| **5** | 完全覆盖，信息完整准确，可直接回答 |
| **4** | 基本覆盖，有小幅信息缺失但不影响核心回答 |
| **3** | 部分覆盖，能提供方向但缺少关键细节 |
| **2** | 有限覆盖，仅有零散相关信息，无法形成有效回答 |
| **1** | 未覆盖，路由文件中无相关信息 |

### 指标查询类（双维度评分）

| 分数 | 定义 |
|------|------|
| **5** | 现状描述完整 + 查询方式明确（表名/dashboard/技能） |
| **4** | 现状描述基本完整 + 查询方式有但不够具体 |
| **3** | 仅有现状描述或仅有查询方式，缺另一半 |
| **2** | 两个维度都有零散信息但不完整 |
| **1** | KB 中无相关信息 |

非 5/5 的评分均会给出具体缺失内容和建议补充的文件/章节。
