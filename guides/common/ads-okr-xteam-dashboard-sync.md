# Ads OKR Epic Dashboard Sync (ads-okr-xteam-dashboard-sync) Guide

> **Contributors**: luka.yang ｜ **最后更新**：2026-06-03 ｜ [GitLab](https://git.garena.com/shopee/search_recommend/ai-copilot/ads-workspace/-/blob/master/guides/common/ads-okr-xteam-dashboard-sync.md)
> **Language**: [English](ads-okr-xteam-dashboard-sync.md) | [中文](ads-okr-xteam-dashboard-sync.zh-CN.md)

Sync `dashboard-meta.json` project tracking data to a Google Sheet, matching rows by Epic Key column.

**Trigger keywords**: "sync dashboard to gsheet", "同步 dashboard 到表格", "dashboard sync", "dashboard 同步"

---

## Scenario 1: Sync all rows in a sheet

> **You**: `/ads-okr-xteam-dashboard-sync --gsheet https://docs.google.com/spreadsheets/d/1t9tZcHIXGR1FuFrOjr8leMncLXdRLDY6EQRP7Qvyq0k/edit?gid=797823418`
>
> **AI**: Extracts spreadsheetId and gid from the link, reads Epic Key column A, finds each `dashboard-meta.json`, writes B:O columns (phase, PRD, roles, teams, PICs, epic file, todos, etc.) back to the sheet. Reports success/skip counts.

---

## Scenario 2: Dry-run preview

> **You**: `同步 dashboard 到表格 --gsheet <link> --dry-run`
>
> **AI**: Reads and extracts data but does not write to the sheet. Shows what would be written for verification.

---

## Scenario 3: Sync for a specific quarter

> **You**: `dashboard sync --gsheet <link> --quarter 2026q1`
>
> **AI**: Looks for `dashboard-meta.json` under `docs/team/00.paid-ads-dev/10.trd-prd-td-list/2026q1/` instead of the current quarter.

---

## Prerequisites

- Google Sheet must have an Epic Key column (default: column A)
- `dashboard-meta.json` must exist for each project (generated by `ads-xteam-runner` / `ads-project-tracker-bot`)
- Google OAuth `~/credentials.json` configured; token cached at `~/.config/ads-workspace/token_sheets_rw.json`

## Column Mapping

| Column | Header | Source |
|--------|--------|--------|
| A | Epic Key | Input (not overwritten) |
| B | Phase | `phase.current_step_name` |
| C | PRD | `prd_url` → HYPERLINK |
| D | PJM | `roles.pjm` (email prefix) |
| E | PM | `roles.pm` (email prefix) |
| F | QA | `roles.qa` (email prefix) |
| G | Teams | `participant_teams` |
| H | PICs | `roles.pics` (team: name) |
| I | Leaders | `roles.leaders` (team: name) |
| J | Epic File | `business_epic.main_file` → GitLab HYPERLINK |
| K | MR | `business_epic.mr_url` → HYPERLINK |
| L | PRD Issues | `prd_quality` (required/active) |
| M | Todo Progress | `todos` (done/total) |
| N | Todo Open | `todos.open` |
| O | Todo Blocked | `todos.blocked` |
