# Ads Data Analyze (ads-data-analyze) 使用指南

> **语言**: [English](ads-data-analyze.md) | [中文](ads-data-analyze.zh-CN.md)

分析查询结果，生成洞察报告。支持多子任务迭代分析（逐步积累发现）和扩展动作（写表文档、导出数据、建议后续查询）。

**触发关键词**: "ads-data-analyze", "analyze results", "分析结果", "generate report", "生成报告", "数据洞察", "帮我分析数据"

---

## 使用场景

- **直接使用**: `/ads-data-analyze` + 粘贴数据 — 有查询结果时直接分析
- **被委托调用**: 由 `ads-data-text2da` 在 SQL 执行完成后自动调用
- **迭代模式**: 多子任务分析时，跨迭代积累发现

## 分析能力

| 能力 | 说明 |
|------|------|
| 数据验证 | 检查 null 值、异常零值、数据完整性 |
| 模式识别 | 趋势、异常（DoD >50%、WoW >30%）、离群值 |
| 派生指标 | CTR、CVR、CPC、ROAS、CIR、日环比/周环比 |
| 交叉验证 | 与前序子任务发现进行比对 |

---

## 扩展动作

| 动作 | 说明 |
|------|------|
| 写表文档 | 基于分析发现更新表知识库文档 |
| 导出数据 | 保存结果为 CSV 到个人目录 |
| 建议后续查询 | 基于发现推荐进一步查询方向 |

---

## 关联技能

| 技能 | 关系 |
|------|------|
| `ads-data-text2da` | 编排者：生成 SQL 后委托分析 |
| `ads-data-sql-executor` | 执行 SQL 后将结果传给本 skill |
