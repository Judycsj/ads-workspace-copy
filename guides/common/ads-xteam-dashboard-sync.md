# Ads Dashboard Sync (ads-xteam-dashboard-sync) Guide

> **Contributors**: luka.yang ｜ **最后更新**：2026-06-29 ｜ [GitLab](https://git.garena.com/shopee/search_recommend/ai-copilot/ads-workspace/-/blob/master/guides/common/ads-xteam-dashboard-sync.md)
> **Language**: [English](ads-xteam-dashboard-sync.md) | [中文](ads-xteam-dashboard-sync.zh-CN.md)

Sync `dashboard-meta.json` project tracking data to a Google Sheet. Auto-discovers all projects under the quarter directory, adds new rows automatically, and sorts by Epic Key timestamp.

**Trigger keywords**: "sync dashboard to gsheet", "同步 dashboard 到表格", "dashboard sync", "dashboard 同步"

---

## Scenario 1: Sync all rows in a sheet

> **You**: `/ads-xteam-dashboard-sync --gsheet https://docs.google.com/spreadsheets/d/1t9tZcHIXGR1FuFrOjr8leMncLXdRLDY6EQRP7Qvyq0k/edit?gid=797823418`
>
> **AI**: Extracts spreadsheetId and gid from the link, reads Epic Key column A, finds each `dashboard-meta.json`, writes B:AD columns (project ID, summary, priority, phase progress, roles, teams, PICs, epic file, team files, TD quality, todos, blockers, open TODO details, etc.) back to the sheet with section-colored formatting. Reports success/skip counts.

---

## Scenario 2: Dry-run preview

> **You**: `同步 dashboard 到表格 --gsheet <link> --dry-run`
>
> **AI**: Reads and extracts data but does not write to the sheet. Shows what would be written for verification.

---

## Scenario 3: Sync for a specific quarter

> **You**: `dashboard sync --gsheet <link> --quarter 2026q1`
>
> **AI**: Looks for `dashboard-meta.json` under `docs/team/00.paid-ads-dev/10.trd-prd-td-list/2026q1/` instead of the current quarter.

---

## Prerequisites

- Google Sheet must exist (script auto-manages column A Epic Keys and B:AD data)
- `dashboard-meta.json` must exist for each project (generated by `ads-xteam-runner` / `ads-project-tracker-bot`)
- Google OAuth `~/credentials.json` configured; token cached at `~/.config/ads-workspace/token_sheets_rw.json`

## Column Mapping

| Column | Header | Source |
|--------|--------|--------|
| A | Epic Key | Input (not overwritten) |
| B | Project ID | `project_id` |
| C | Summary | `summary` |
| D | Priority | `priority` |
| E | PRD | `prd_url` → HYPERLINK |
| F | Epic | `business_epic.root` → GitLab tree HYPERLINK |
| G | Deadline | Fixed "N/A" (not in JSON) |
| H | PJM | `roles.pjm` (email prefix) |
| I | PM | `roles.pm` (email prefix) |
| J | QA | `roles.qa` (email prefix) |
| K | Teams | `participant_teams` |
| L | Dev PICs | `roles.pics` (team: name) |
| M | Leaders | `roles.leaders` (team: name) |
| N | Phase | `phase.current_step_name` |
| O | Progress | `phase.current_step` → N/11 (XX%) |
| P | Epic File | `business_epic.main_file` → GitLab HYPERLINK |
| Q | Team Files | `business_epic.team_files` → GitLab links per team |
| R | MR | `business_epic.mr_url` → HYPERLINK |
| S | PRD Issues | `prd_quality` (required/active) |
| T | TD Status | `td_quality.overall_status` |
| U | TD Details | `td_quality.sides` (team: status(issues)) |
| V | Todo Progress | `todos` (done/total) |
| W | Todo Open | `todos.open` |
| X | Todo Blocked | `todos.blocked` |
| Y | Todo Pending | `todos.pending` |
| Z | Todo InProgress | `todos.in_progress` |
| AA | Todo Skipped | `todos.skipped` |
| AB | Blockers | `todos.items` (blocking=true, multi-line) |
| AC | Open TODOs | `todos.items` (open, multi-line) |
| AD | Updated At | `updated_at` |
