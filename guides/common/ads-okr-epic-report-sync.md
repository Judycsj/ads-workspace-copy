# Ads OKR Epic Report Sync (ads-okr-epic-report-sync) Guide

> **Contributors**: luka.yang ｜ **最后更新**：2026-05-28 ｜ [GitLab](https://git.garena.com/shopee/search_recommend/ai-copilot/ads-workspace/-/blob/master/guides/common/ads-okr-epic-report-sync.md)
> **Language**: [English](ads-okr-epic-report-sync.md) | [中文](ads-okr-epic-report-sync.zh-CN.md)

Sync `epic-report-meta.json` data to a Google Sheet, matching rows by Epic_File Key column.

**Trigger keywords**: "sync epic report to gsheet", "同步 epic 到表格", "epic report sync", "epic 报告同步"

---

## Scenario 1: Sync all rows in a sheet

> **You**: `/ads-okr-epic-report-sync --gsheet https://docs.google.com/spreadsheets/d/1waq2gLBcfBRMBO7fRCYkkYei-j0Fbz9INcby29IEiAU/edit?gid=2034964463`
>
> **AI**: Extracts spreadsheetId and gid from the link, reads Epic_File Key column, runs `extract_epic_data.py` to read each `epic-report-meta.json`, writes B:R columns back to the sheet. Reports success/skip counts.

---

## Scenario 2: Sync with a specific sheet name

> **You**: `同步 epic 报告到表格 --gsheet 1waq2gLBcfBRMBO7fRCYkkYei-j0Fbz9INcby29IEiAU --sheet 平台出价`
>
> **AI**: Uses the specified sheet name directly instead of resolving from gid.

---

## Scenario 3: Sync for a different quarter or team

> **You**: `epic report sync --gsheet <link> --quarter 2026q1 --team 01.ads-engineering`
>
> **AI**: Looks for `epic-report-meta.json` under `docs/team/01.ads-engineering/10.trd-prd-td-list/2026q1/` instead of the default path.

---

## Prerequisites

- Google Sheet must have an `Epic_File Key` column (default: column A)
- `epic-report-meta.json` must exist for each KP (generated by `ads-okr-epic-report`)
- MCP Google Drive tools must be available

## Column Mapping

| Column | Header | Source |
|--------|--------|--------|
| A | Epic_File Key | Input (not overwritten) |
| B | epic-name | `kp_title` |
| C | 交付目标 | `deliverable` |
| D | KA进展 | `key_progress` |
| E | 实验 | `experiment` |
| F | 风险 | `risk` |
| G | 下一步 | `next_steps` |
| H | epic-file | `epic_file_gitlab_url` → HYPERLINK |
| I | epic-report | `epic_report_gitlab_url` → HYPERLINK |
| J | Owner | `owner` |
| K | Contributor | `contributor` |
| L | TDStep | `step` |
| M | eta | `eta` (YYYYMMDD) |
| N | effort | `effort` |
| O | start | `start` (YYYYMMDD) |
| P | update | `last_update` |
| Q | KA进度 | `done_count/total_count` |
| R | 状态 | `status` (emoji) |
