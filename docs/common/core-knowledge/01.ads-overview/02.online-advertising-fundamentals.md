## 1.2 在线广告基础 / Online Advertising Fundamentals

### 1.2.1 广告生态与核心角色 / The Advertising Ecosystem and Core Roles

<!-- last_translated: 2026-06-05T09:27:32.218094+00:00 -->

There are three core roles in the advertising ecosystem:

- **Advertiser**: Wants to promote products or services, and is willing to pay for traffic to gain user attention and conversions
- **Publisher (Platform)**: Owns user traffic (e.g., the search and recommendation pages in the Shopee App), provides ad placement slots, and facilitates transactions
- **User**: Browses and consumes content; their behavior (browsing, clicking, purchasing) is the ultimate source of advertising value

The essence of advertising is **traffic monetization** — selling user traffic to specific advertisers at an appropriate price. The two most important objects in this system are **traffic scenarios** and **ad inventory**. The core function of the advertising system is to match traffic with ads, generating value for advertisers while charging for traffic.

### 1.2.2 广告和搜推的异同点 / Similarities and Differences Between Ads and Search/Recommendation

<!-- last_translated: 2026-06-05T09:27:45.426610+00:00 -->

The advertising system and the search/recommendation system are highly similar in technical architecture (recall → ranking → display), but differ fundamentally in business model:

| Business Model | Search & Recommendation (Search & RCMD) | Advertising |
| ------ | ----------------------------------- | ------------------------------------------------------------------------ |
| Market Structure | Two-sided market (User ↔ Platform) | Three-sided market (User ↔ Platform ↔ Advertiser) |
| Core Serving Target | User | Advertiser |
| Ultimate Goal | Improve user experience and retention (DAU, retention, orders, time spent, etc.) | Maximize commercial revenue and advertiser ROI |
| Guiding Philosophy | User-centric: everything is for improving user experience, efficiency, and engagement | Business-goal driven: maximize advertiser value within user experience constraints |
| Ranking Mechanism | Ranked by "relevance/interest score": Score = f(user, item) | Ranked by "commercial value (eCPM)": Score = f(user, ad) × Bid |
| Strategy Mechanisms | Diversity and re-ranking (avoiding filter bubbles), real-time user behavior feedback, interest exploration, search-recommendation linkage | Auction & Deduction, Bidding strategies, Pacing, Targeting |

### 1.2.3 广告形式与交易模式 / Ad Formats and Transaction Models

#### 1.2.3.1 按投放机制分类 / Classification by Delivery Mechanism

<!-- last_translated: 2026-06-05T09:27:37.852418+00:00 -->

| Delivery Mechanism | Characteristics | Ad Placement | Ranking Method | Typical Billing | Typical Shopee Scenarios |
| ----- | -------------------------------------------- | -------------------------------------- | --------------------------- | ---------- | -------------------------------------------------------- |
| Search Ads | Triggered by active user search; high intent, high conversion rate | **Dynamic blending**: ads mixed with organic results, insertion position determined by algorithm | Keyword relevance + eCPM auction ranking | CPC / oCPX | Product cards on the search results page |
| Feed Ads | Proactively recommended by the platform; blended into content feed, visually indistinguishable from organic content, more natural user experience; balances exposure and performance conversion | **Dynamic blending**: ads mixed with organic content, insertion position determined by algorithm | Personalized recommendation + eCPM auction ranking, unified with organic content ranking | CPC / oCPX | Product cards on recommendation pages (Daily Discover / YMAL) |
| Display Ads | Fixed positions, strong visual exposure, suitable for brand awareness; ads are visually distinct from organic content, identifiable as ads at a glance | **Fixed slots**: positions predetermined (e.g., top-of-page banner), not mixed with organic content | Scheduled by contract or CPM auction, not participating in personalized content ranking | CPM / contract package | Homepage banners (Homepage Brand Ads), top search brand zones (Search Brand Ads) |

#### 1.2.3.2 按内容载体分类 / Classification by Content Type

<!-- last_translated: 2026-06-05T09:27:32.130230+00:00 -->

| Content Type | Characteristics | Typical Shopee Scenarios |
| ---- | ------------------------- | ----------- |
| Image & Text | Low production cost, wide applicability, most common form in e-commerce | Product cards, shop cards |
| Short Video | Rich media format, high information density, strong user attention | Short video feed |
| Live Streaming | Real-time interaction, host-driven conversions, combines content seeding and instant transactions | Live room promotion cards |

The two dimensions can be freely combined. For example, a video ad can appear on the search results page (search ad) or on the recommendation page (feed ad); a live streaming ad can similarly appear in different delivery positions.

#### 1.2.3.3 交易模式演进 / Evolution of Transaction Models

<!-- last_translated: 2026-06-05T09:27:49.945417+00:00 -->

Guaranteed Delivery (Contract Ads)
  └─ Fixed by time/position, guaranteed delivery, suitable for brand ads
       ↓
Auction-based (Programmatic Auction)
  └─ Real-time bidding, pay by performance, suitable for performance ads (main model of Shopee Paid Ads)
       ↓
Programmatic Trading
  └─ Automated buying/selling via DSP/SSP/Ad Exchange, cross-platform delivery

### 1.2.4 广告核心指标体系 / Core Advertising Metrics

<!-- last_translated: 2026-06-05T09:27:48.828943+00:00 -->

Understanding the following metrics is a prerequisite for learning subsequent modules on bidding, estimation, and selling.

**Advertising Funnel and Performance Metrics:**

```
Impression → Click → Conversion → GMV
     │            │              │
     └─ CTR       └─ CVR         └─ AOV
   Click/Imp     Conv/Click      GMV/Orders
```


| Metric | Full Name | Definition |
| -------- | ------------------------ | ------------------------------------------------------------------------------ |
| **CTR** | Click-Through Rate | Click rate = Clicks / Impressions |
| **CVR** | Conversion Rate | Conversion rate = Conversions / Clicks |
| **AOV** | Average Order Value | Average order value = GMV / Conversions; reflects the value of a single order from ads, affecting ROAS and pGMV estimation |
| **CPC** | Cost Per Click | Cost per click = Ad spend / Clicks |
| **CPA** | Cost Per Action | Cost per action = Ad spend / Conversions |
| **ROAS** | Return On Ad Spend | Return on ad spend = GMV driven by ads / Ad spend |
| **eCPM** | effective Cost Per Mille | Effective revenue per thousand impressions = (Revenue from a single ad / Impressions of that ad) × 1000; the core comparison unit for ad ranking, determining which ad wins the auction |
| **RPM** | Revenue Per Mille | Platform's total ad revenue per thousand traffic requests = (Total ad revenue / Total requests) × 1000; measures the overall traffic monetization efficiency of the platform. RPM ≈ Σ(eCPM of each ad slot × fill rate) |

### 1.2.5 广告归因模型 / Ad Attribution Models

#### 1.2.5.1 归因类型 / Attribution Types

<!-- last_translated: 2026-06-05T09:27:35.076789+00:00 -->

| Attribution Type | Description | Typical Window |
| ------------------------------- | ------------------------------ | ---------- |
| Click-through Attribution | Conversions that occur within the attribution window after a user clicks an ad are attributed to that ad | 7 days / 14 days |
| View-through Attribution | Conversions that occur within the attribution window after a user only views an ad (without clicking) are attributed to that ad | 1 day |


- **Attribution Window**: A time period following an ad interaction (click/impression), within which any conversion is attributed to that ad

#### 1.2.5.2 归因优先级与逻辑 / Attribution Priority and Logic

<!-- last_translated: 2026-06-05T09:27:32.718462+00:00 -->

- 1. **Click takes priority over View**: If both a click and an impression exist within the attribution window, the conversion is attributed to the click touchpoint
- 2. **Last Touch principle**: When there are multiple interactions of the same type, the last touchpoint receives attribution
- 3. Attribution determination process: Conversion occurs → Check whether there is a Click within the attribution window → If yes, attribute to Last Click → If not, check for a View → Attribute to Last View → If neither, no attribution

#### 1.2.5.3 Direct vs Broad 归因 / Direct vs Broad Attribution

<!-- last_translated: 2026-06-05T09:27:32.458050+00:00 -->

| Attribution Method | Description |
| ------------------------ | ------------------------ |
| Direct Attribution | The advertised product clicked/viewed and the product ultimately converted are the same product |
| Broad Attribution | The advertised product clicked/viewed and the product ultimately converted belong to the same shop |
