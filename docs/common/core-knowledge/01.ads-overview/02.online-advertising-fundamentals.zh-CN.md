## 1.2 在线广告基础 / Online Advertising Fundamentals

### 1.2.1 广告生态与核心角色 / The Advertising Ecosystem and Core Roles


广告生态中有三个核心角色：

- **广告主（Advertiser）**：希望推广商品或服务，愿意为流量付费以获取用户关注和转化
- **平台（Publisher）**：拥有用户流量（如 Shopee App 的搜索页、推荐页），提供广告展示位置并撮合交易
- **用户（User）**：浏览和消费内容，其行为（浏览、点击、购买）是广告价值的最终来源

广告的本质是**流量售卖**——将用户流量按照合适的价格售卖给特定的广告主。这个系统里最重要的两个对象是**流量场景**和**广告集合**，广告系统的核心功能就是撮合流量和广告，为广告主带来价值的同时收取流量费用。

### 1.2.2 广告和搜推的异同点 / Similarities and Differences Between Ads and Search/Recommendation


广告系统与搜索推荐系统在技术架构上高度相似（召回→排序→展示），但在业务模式上有本质差异：


| 业务模式   | 搜索 & 推荐 (Search & RCMD)             | 广告 (Advertising)                                                         |
| ------ | ----------------------------------- | ------------------------------------------------------------------------ |
| 市场结构   | 双边市场（用户 ↔ 平台）                       | 三边市场（用户 ↔ 平台 ↔ 广告主）                                                      |
| 核心服务对象 | 用户 (User)                           | 广告主 (Advertiser)                                                         |
| 最终目标   | 提升用户体验与粘性（DAU、留存、订单、时长等）            | 最大化商业收入 (Revenue) 和广告主 ROI                                               |
| 指导思想   | 用户中心制：一切为了提升用户体验、效率与粘性              | 商业目标驱动：在用户体验约束下，最大化广告主价值                                                 |
| 排序机制   | 按"相关性/兴趣分"排序： Score = f(user, item) | 按"商业价值(eCPM)"排序： Score = f(user, ad) × Bid                               |
| 策略机制   | 多样性与重排（避免信息茧房）、用户行为实时反馈、兴趣探索、搜推联动   | 售卖机制 (Auction & Deduction)、出价策略 (Bidding)、预算分配 (Pacing)、人群定向 (Targeting) |

### 1.2.3 广告形式与交易模式 / Ad Formats and Transaction Models

#### 1.2.3.1 按投放机制分类 / Classification by Delivery Mechanism



| 投放机制  | 特点                                           | 广告位                                    | 排序方式                        | 典型计费       | Shopee 典型场景                                              |
| ----- | -------------------------------------------- | -------------------------------------- | --------------------------- | ---------- | -------------------------------------------------------- |
| 搜索广告  | 用户主动搜索触发，意图明确，转化率高                           | **动态混排**：广告与自然结果混排，由算法决定插入位置           | 关键词相关性 + eCPM 竞价排序          | CPC / oCPX | 搜索结果页商品卡片                                                |
| 信息流广告 | 平台主动推荐触发，融入内容流，外观与自然内容高度一致，用户体验更自然；兼顾曝光和效果转化 | **动态混排**：广告与自然内容混排，由算法决定插入位置           | 个性化推荐 + eCPM 竞价排序，与自然内容统一排序 | CPC / oCPX | 推荐页商品卡片（Daily Discover / YMAL）                           |
| 展示广告  | 固定位置、强视觉曝光，适合品牌认知；广告与自然内容有明显视觉区分，用户一眼可识别为广告  | **固定坑位**：位置预先确定（如页面顶部 Banner），不与自然内容混排 | 按合约排期或 CPM 竞价，不参与个性化内容排序    | CPM / 合约包断 | 首页 Banner（Homepage Brand Ads）、搜索顶部品牌专区（Search Brand Ads） |

#### 1.2.3.2 按内容载体分类 / Classification by Content Type



| 内容载体 | 特点                        | Shopee 典型场景 |
| ---- | ------------------------- | ----------- |
| 图文   | 制作成本低，适用范围广，电商最常见的形式      | 商品卡片、店铺卡片   |
| 短视频  | 富媒体形式，信息量大，用户注意力强         | 短视频流        |
| 直播   | 实时互动，主播讲解驱动转化，兼具内容种草与即时成交 | 直播间推广卡片     |


两个维度可以自由组合，例如：一条视频广告可以出现在搜索结果页（搜索广告）或推荐页（信息流广告）；一条直播广告同样可以出现在不同的投放位置。

#### 1.2.3.3 交易模式演进 / Evolution of Transaction Models


```
合约广告（Guaranteed Delivery）
  └─ Fixed by time/position, guaranteed delivery, suitable for brand ads
       ↓
竞价广告（Auction-based）
  └─ Real-time bidding, pay by performance, suitable for performance ads (main model of Shopee Paid Ads)
       ↓
程序化交易（Programmatic）
  └─ Automated buying/selling via DSP/SSP/Ad Exchange, cross-platform delivery
```

### 1.2.4 广告核心指标体系 / Core Advertising Metrics


理解以下指标是学习后续出价、预估、售卖等模块的前置条件。

**广告漏斗与效果指标：**

```
Impression → Click → Conversion → GMV
     │            │              │
     └─ CTR       └─ CVR         └─ AOV
   Click/Imp     Conv/Click      GMV/Orders
```


| 指标       | 全称                       | 含义                                                                             |
| -------- | ------------------------ | ------------------------------------------------------------------------------ |
| **CTR**  | Click-Through Rate       | 点击率 = 点击数 / 曝光数                                                                |
| **CVR**  | Conversion Rate          | 转化率 = 转化数 / 点击数                                                                |
| **AOV**  | Average Order Value      | 平均客单价 = GMV / 转化数；反映广告带来的单笔订单价值，影响 ROAS 和 pGMV 预估                              |
| **CPC**  | Cost Per Click           | 每次点击成本 = 广告花费 / 点击数                                                            |
| **CPA**  | Cost Per Action          | 每次转化成本 = 广告花费 / 转化数                                                            |
| **ROAS** | Return On Ad Spend       | 广告支出回报率 = 广告带来的 GMV / 广告花费                                                     |
| **eCPM** | effective Cost Per Mille | 每千次曝光的有效收入 = (单条广告收入 / 该广告曝光数) × 1000；是广告排序的核心比较单位，决定哪条广告赢得竞价                  |
| **RPM**  | Revenue Per Mille        | 平台每千次流量请求的总广告收入 = (全部广告收入 / 总请求数) × 1000；衡量平台整体流量变现效率。RPM ≈ Σ(各广告位 eCPM × 填充率) |

### 1.2.5 广告归因模型 / Ad Attribution Models

#### 1.2.5.1 归因类型 / Attribution Types



| 归因类型                            | 说明                             | 典型窗口       |
| ------------------------------- | ------------------------------ | ---------- |
| Click-through Attribution（点击归因） | 用户点击广告后，在归因窗口内产生的转化归因到该广告      | 7 天 / 14 天 |
| View-through Attribution（曝光归因）  | 用户仅看到广告（未点击），在归因窗口内产生的转化归因到该广告 | 1 天        |


- **归因窗口（Attribution Window）**：广告交互（点击/曝光）发生后的一段时间，在此期间内的转化被归因到该广告

#### 1.2.5.2 归因优先级与逻辑 / Attribution Priority and Logic


- 一、**Click 优先于 View**：若归因窗口内同时存在点击和曝光，转化归因到点击触点
- 二、**Last Touch 原则**：同类型多次交互时，最后一次触点获得归因
- 三、归因判定流程：转化发生 → 检查归因窗口内是否有 Click → 有则归因到 Last Click → 没有则检查 View → 归因到 Last View → 都没有则不归因

#### 1.2.5.3 Direct vs Broad 归因 / Direct vs Broad Attribution



| 归因方式                     | 说明                       |
| ------------------------ | ------------------------ |
| Direct Attribution（直接归因） | 用户点击/曝光的广告商品与最终转化商品为同一商品 |
| Broad Attribution（间接归因）  | 用户点击/曝光的广告商品与最终转化商品为同一店铺 |
