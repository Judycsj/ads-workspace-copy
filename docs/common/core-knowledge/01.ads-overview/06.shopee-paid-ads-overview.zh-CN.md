## 1.6 Shopee Paid Ads 业务介绍 / Shopee Paid Ads Business Overview

### 1.6.1 流量入口和形态 / Traffic Entry Points and Formats

#### 1.6.1.1 商品广告 / Product Ads


商品广告（Product Ads）是 Shopee 最主要的广告形式，出现在搜索结果页和推荐页等场景。Product Ads 是 Shopee 广告消耗占比最高的效果广告类型，覆盖搜索（Search）和推荐（RCMD）双场景，支持 Manual CPC、eCPC、Target ROI 和 GMV MAX 等多种出价模式（详见 [§1.6.2](#162-广告投放产品和链路概览)），采用 GSP 二价拍卖、按点击计费。适合所有希望提升商品曝光和销量的商家——从初次投放的中小卖家到成熟品牌商家均适用，是新商家入门广告投放的首选类型。

![商品广告流量入口](./img/Xnip2026-03-20_16-34-18.jpg)

#### 1.6.1.2 店铺广告 / Shop Ads


店铺广告（Shop Ads）以店铺卡片形式出现在搜索结果页等场景。Shop Ads 属于店铺级推广，引导用户进入店铺页面浏览更多商品，推荐主体为"店铺×商品"组合。适合希望提升店铺整体流量和品牌认知的商家，尤其是多品类店铺和有持续上新需求的卖家。

![店铺广告流量入口](./img/Xnip2026-03-20_16-42-37.jpg)

#### 1.6.1.3 品牌广告 / Brand Ads


品牌广告（Brand Ads）以 Banner 等强视觉形式出现在搜索顶部和首页等场景。Brand Ads 属于固定坑位的展示广告（参见 [§1.2.3.1](02.online-advertising-fundamentals.zh-CN.md#1231-按投放机制分类)），不与自然内容动态混排，采用 GFP 一价拍卖、按点击计费，视觉冲击力强。适合有品牌建设需求和较大预算的品牌广告主，典型场景包括大促期间的品牌曝光、新品首发和品牌活动推广。

![品牌广告流量入口](./img/Xnip2026-03-20_16-42-49.jpg)

#### 1.6.1.4 直播广告 / Live Ads


直播广告（Live Ads）以直播间推广卡片形式出现在推荐页等场景。Live Ads 通过推广直播间，利用主播实时互动驱动用户转化，推荐主体为"直播间×商品"，按曝光（impression）计费。适合有直播运营能力的商家，尤其在大促活动、新品首发和日常店播等需要实时互动的场景中效果显著。

![直播广告流量入口](./img/Xnip2026-03-20_16-43-01.jpg)

#### 1.6.1.5 视频广告 / Video Ads


视频广告（Video Ads）以短视频形式出现在推荐页和视频流等场景。Video Ads 以短视频为内容载体（参见 [§1.2.3.2](02.online-advertising-fundamentals.zh-CN.md#1232-按内容载体分类)），信息量大、用户注意力强，推荐主体为"视频×商品"，按曝光（impression）计费，采用 GSP 二价拍卖。适合有视频内容制作能力的商家，通过内容种草驱动商品发现和转化，尤其适用于服饰、美妆、食品等视觉展示效果好的品类。

![视频广告流量入口](./img/Xnip2026-03-20_16-43-18.jpg)

### 1.6.2 广告投放产品和链路概览 / Ad Campaign Products and Pipeline Overview





|      | Product Ads                                           | Brand & Shop Ads            | Video Ads                                                              | Live Ads                                                      |
| ---- | ----------------------------------------------------- | --------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------- |
| 竞价产品 | Target ROI2, Simple ROI2, Manual & eCPC, Shop GMV Max | Auto Mode, Manual CPC& eCPC | Max View, Max GMV                                                      | Max GMV 2.0, Target 2.0, Max GMV 1.0, Target 1.0, Max View    |
| 扣费形式 | GSP（二价拍卖，多坑）                                          | GFP（一价拍卖，单坑）                | GSP（二价拍卖，多坑）                                                           | First-Price（一价，含 rankcap & bidcap 上限约束，多坑拍卖）                  |
| 计费点  | click（逐步迁移至 impression）                               | click                       | impression                                                             | impression                                                    |
| 投放场景 | Search: SRP； RCMD: DD / YMAL / Game / Cart_Unify      | SRP / Game / Display        | RCMD: DD / YMAL / Minifeed / ForYou / VideoPage； Homepage； Search； PDP | Discover / For You / Autolanding / Video Tab / Homepage / PDP |
| 推荐主体 | Item                                                  | Shop x Item                 | Video x Item                                                           | Stream room x Item                                            |


> 注：以上的流量入口仅包含明投，即在广告投放平台告知广告主的流量入口，实际上预算过剩的广告供给会通过暗投的方式在其他流量入口进行投放消耗（比如 Product Ads 会暗投在 Shop/Live/Video 等流量入口）。
