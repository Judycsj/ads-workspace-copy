## 5.4 计费与扣费/Billing & Deduction

本章节介绍广告计费和扣费体系的核心概念，包括充值、扣费流程、收入定义和赔付机制。

### 5.4.1 计费模式/Billing Modes

| 模式 | 全称 | 触发事件 | 说明 |
|------|------|---------|------|
| **CPC** | Cost Per Click | 点击 | 按点击计费，最常用 |
| **CPM** | Cost Per Mille | 曝光（批量） | 按千次曝光计费，通过 Batcher 聚合（30s 超时，最多 50 次/批） |
| **OCPM** | Optimized CPM | 曝光（优化） | 优化 CPM，店铺级批量处理 |
| **CPS** | Cost Per Sale | 成交 | 按成交计费，仅走 TMS 链路 |
| **ECPC** | Enhanced CPC | 点击（增强） | 增强 CPC，出价上限 4 倍 |

### 5.4.2 扣费流程概述/Deduction Flow Overview

扣费分为两个阶段：

**在线预扣费/Online Pre-Deduction**（`paidads-deduction`）：
1. 消费 Tracking 事件
2. 反作弊过滤 → 基础校验 → 单商品检查 → 价格提取
3. Redis SETNX 去重（标准 CPC/CPM：1h TTL；OCPM：24h TTL）
4. 模型状态检查（广告/计划/账户是否有效）
5. 价格上限检查（4 倍卖家出价）
6. Campaign 日预算检查 → 账户余额预检
7. 发送扣费事件到 Kafka

**离线扣费/Offline Deduction**（`paidads-offline-deduction`）：
1. 消费扣费事件
2. Translog 去重（预事务查询 + MySQL 唯一键约束双层保障）
3. 三级预算上限检查：账户+积分、Campaign 日预算、广告位分配
4. DB 事务执行（SELECT FOR UPDATE → credits/account/campaign_daily 更新 → translog 插入）
5. 下游输出：translog、财务事件、重新索引

### 5.4.3 充值与账户/Topup & Account

广告主通过充值（Topup）向广告账户注入资金。账户余额分为：
- **现金余额/Cash Balance**：广告主实际充值的资金
- **Free Credit/免费积分**：平台发放的促销积分（如赔付注入的积分）

扣费时按规则消耗不同类型的余额。

### 5.4.4 收入概念/Revenue Concepts

| 概念 | 定义 |
|------|------|
| **Gross Revenue/总收入** | 广告主的全部广告支出（含税、含各类扣费） |
| **Net Revenue/净收入** | 总收入扣除返利、过期金额等 |
| **expenditure_amt** | 广告花费（税前，不含 Display/Expiry） |
| **Net Take Rate** | net_ads_revenue / buyer_checkout_gmv |

### 5.4.5 赔付机制/Auto Rebate

Auto Rebate 是 ROAS/ROI 保护机制：当 Campaign 的实际 ROI 低于保护阈值时，系统通过注入 Free Credit 补偿广告主。

**三层架构**：
1. **规则层**（DE 离线计算）：赔付周期、订单阈值、ROI 保护阈值、计算公式
2. **服务层**（`auto-rebate`）：状态机管理赔付生命周期，创建赔付订单，调用 Topup 注入积分
3. **数仓层**：存储应赔/实赔/充值明细/translog，供分析和对账

**关键概念**：
- **应赔/Expected Rebate**：理论赔付金额 = 花费 - 受保护 ADVV
- **实赔/Final Rebate**：经人工审核、风控后的实际赔付金额
- **ADVV**：广告主价值 = broad_gmv × target_cir。Rapid Boost/Campaign Surge 场景除以 0.9
- **订单阈值**：ROI2/MPD ≥ 5 单，GMS ≥ 10 单
- **赔付上限**：`min(应赔, 花费 × rebate_amt_cap)`

**状态机**：invalid → calculating → need_manual_review / no_rebate_needed / pending_rebate → order_created → rebate_done
