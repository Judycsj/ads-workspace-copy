## 5.7 Ads Dimensions & Business Concepts Index

This document serves as the **unified index layer** for ads dimensions and business concepts, mapping user natural language to canonical data fields and business scope classifications.

### 5.7.1 Purpose

| Scenario | How to Use |
|----------|-----------|
| **KB QA** | User question → grep this doc to match dimension/concept keywords → locate definitions and detail links |
| **Data Analysis** | User query intent → synonym expansion (dimension mapping) + scope identification (business classification) → precise table/field selection |

**Three keyword categories**:

| Category | Examples | Purpose |
|----------|---------|---------|
| Dimension keywords | region, campaign, shop, ads_id, entry_point, pricing_type | Synonym expansion: user says "seller" → seller, shop, shop_id |

### 5.7.3 Core Entity Dimensions

Source: [Key Dimensions & Metrics §5.2.1](02.key-dimensions-and-metrics.md)

Foundational entities of the ads data model. All analyses revolve around these entities.

| Entity | Aliases | Primary Key | Description | Typical Use Case |
|--------|---------|-------------|-------------|-----------------|
| Item | 商品, SKU, product, 宝贝, 推广商品, promoted item | `item_id` | Promoted product entity; category/brand/attributes are key sub-dimensions | Item-level performance, category analysis |
| User | 用户, 买家, buyer, consumer, 购买者 | `user_id` | Platform buyer (incl. sellers as buyers); journey: install → register → active | User behavior, audience analysis |
| Shop | 店铺, 卖家, seller, merchant, 商家, 商户 | `shop_id` | 1 seller maps to N shops (one-to-many); shop ≠ seller | Seller-level performance, seller tiering |
| Ads | 广告, ad, 广告单元, 广告创意, promotion | `ads_id` | Ad unit placed on App/Web to boost exposure and purchase probability | Ad-level performance analysis |
| Campaign | 计划, campaign, 推广计划, 广告活动, ad group | `campaign_id` | Group of ads sharing budget, objective, and strategy | Campaign-level budget/performance analysis |
| Pricing Type | 出价类型, 计费模式, billing mode, 竞价类型 | `pricing_type` | CPC/CPM/OCPM/CPS/ECPC | Analysis by billing mode |
| Entrance | 入口, 流量入口, 场景入口, entry point | `entrance` | Frontend area where ads are shown (search=1, daily_discover=3, etc.) | Traffic source analysis |
| Placement | 广告位, 展示位置, 投放位, ad slot | `placement` | Derived from entrance mapping; can refer to display area or ad type | Placement performance comparison |
