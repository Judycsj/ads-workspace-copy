## 5.1 广告数仓体系总览/Ads Data Warehouse Overview

本章节介绍 Shopee 广告数仓的整体架构、分层规范、命名规范和核心表清单。关于数据服务的工程架构（Kafka/Hive 流转），参见 [§3.6 广告数据](../03.ads-engine/06.ads-data.zh-CN.md)。

### 5.1.1 数据架构概念/Data Architecture Concepts

广告数仓围绕两个核心概念组织：

- **数据域/Data Domain**：围绕明确的业务主题（如广告设置 Ads Setup、链路追踪 Trace、流量 Traffic）进行组织，为相关数据资产提供逻辑分组。它是数据资产管理、开发治理和责任归属的基本单元。
- **分析主题/Analysis Topic**：聚焦于特定问题领域的数据分析（如 Take Rate、AB 实验效果），通常需要整合跨多个数据域的数据。分析主题是动态的，随业务需求演进。

### 5.1.2 数仓分层规范/Data Warehouse Layer Convention

广告数仓采用标准分层架构，从底层到顶层依次为：

| 层级 | 全称 | 定义 | 使用场景 |
|------|------|------|---------|
| **ODS** | Operational Data Store | 原始数据层，直接从业务系统或日志接入 | 数据源对接，极少直接查询 |
| **DIM** | Dimension | 维度层，存放实体的描述性属性（广告、广告主、商品等） | 关联 DWD 表过滤事件数据；查找实体在特定时间点的属性 |
| **DWD** | Data Warehouse Detail | 明细层，存放与维度相关的业务事件明细与度量 | Ad-hoc 分析定位根因；构建其他层尚未提供的临时指标 |
| **DWS** | Data Warehouse Summary | 汇总层，按通用维度对业务事件进行聚合 | 使用预计算指标提升查询性能；获取公司范围内口径已对齐的指标 |
| **ADS** | Application Data Store | 应用层，整合单一或跨数据集市的指标 | 为下游产品（Campaign Station、Seller Centre）提供输入；为报表查找特定实体指标 |

各层示例表：

- **DIM**: `dim_advertise`, `dim_advertiser`, `dim_campaign`
- **DWD**: `dwd_advertise_performance_di`, `dwd_advertise_tracking_item_hi`, `dwd_advertiser_deduction_di`, `dwd_advertise_order_attribution_di`
- **DWS**: `dws_advertise_performance_1d`, `dws_advertise_item_performance_1d`, `dws_advertiser_balance_td`
- **ADS**: `ads_advertise_mkt_1d`, `ads_advertiser_mkt_1d`, `ads_advertise_take_rate_v2_1d`

→ 各表的完整字段详情见 [DataMap 索引](../../datamap/)

### 5.1.3 表命名规范/Table Naming Convention

**实体命名/Entity Naming**：

| 实体 | 命名 | 说明 |
|------|------|------|
| 广告 | `advertise` (缩写 `ads`) | 广告投放单元 |
| 广告主 | `advertiser` | 卖家作为广告主的身份 |
| 广告计划 | `campaign` | 共享预算和策略的广告组 |
| 商品 | `item` | 被推广的商品 |
| 入口 | `entrance` | 广告展示的前端区域 |
| 广告位 | `location` | 区域内的具体展示位置 |

**各层命名格式**：

| 层级 | 格式 | 示例 |
|------|------|------|
| ODS（DB 表） | `ods_[接入方式]_{库名}__{表名}_{频率}__{区域}_{安全}_{环境}` | `ods_shopee_order_v4_db__order_v4_tab_df__reg_s1_live` |
| ODS（日志） | `ods_log_[业务]_{模块}_{频率}__{区域}_{安全}_{环境}` | `ods_log_search_ads_tracking_hi__reg_s0_live` |
| DIM | `dim_{维度名}_[扩展]__{区域}_{安全}_{环境}` | `dim_common_item__reg_s0_live` |
| DWD | `dwd_{域}_{粒度}_{事件}_[备注]_{频率}__{区域}_{安全}_{环境}` | `dwd_advertise_performance_di__reg_s0_live` |
| DWS | `dws_{维度}_{事件}_[备注]_{窗口}__{区域}_{安全}_{环境}` | `dws_advertise_performance_1d__reg_s0_live` |
| ADS | `ads_[备注]_{窗口}__{区域}_{安全}_{环境}` | `ads_advertise_take_rate_v2_1d__reg_s0_live` |

**字段命名规范**：实体缩写（如 `advertise` → `ads`），下划线分隔。

### 5.1.4 字段枚举值对照/Field Enum Values

以下字段有标准枚举值定义（具体值列表见各表的 column_info）：

| 字段 | 说明 |
|------|------|
| `placement` | 广告位类型 |
| `entrance` | 广告入口（流量场景） |
| `advertise_status` | 广告状态 |
| `pricing_type` | 定价/出价模式 |
| `keyword_match_type` | 关键词匹配类型 |
| `ads_audit_event` | 广告审核事件 |
| `seller_center_platform_type` | 卖家中心平台类型 |

| 表名 | 层级 | 用途概述 |
|------|------|---------|
