### Graph Engine

当前广告系统使用 Graph Engine 的 DAG 模型编排在线请求、索引、召回和数据处理链路；Graph Manager 负责可视化与编辑，Graph Config 承载 YAML 配置，Graph Engine 执行 DAG。

| 模块/Module | 入口/Link | 最新说明/Current Role |
| --- | --- | --- |
| Graph Manager | [Portal](https://graphmanager.shopee.io/) / [Repo](https://git.garena.com/shopee/deep/searchads/graph-manager) | 在线查看、编辑和校验 Ads DAG；读取 graph-manager-conf 配置，调用 graph-engine 工具渲染 SVG/PNG，并支持跳转 GitLab 提交 MR。 |

### 3.1.0 工程调用关系总览/Engineering Call Graph

架构图不可访问时，可以用下面的文字版回答"各服务之间如何调用"。在线请求链路和数据回流链路是两条互相闭环的主线：

```text
FE / Search / Discovery / Content BFF
  -> ads-engine
       -> API0 AdsRecall -> paidads-recall -> Vespa / Redis / OhMyEmb
       -> API1 AdsInfo   -> paidads-valar.gateway -> Valar Redis
       -> API2 BidInfo   -> bidding-store -> online-bidding
       -> API3 Deduction -> online-bidding DeductionParam / ads-data deduction
       -> API4 AdsUnified -> Shop / Live / BrandMax / Product unified graph
  -> FE impression/click/order tracking
       -> paidads-tracking
       -> paidads-deduction / paidads-report-ng
       -> ultrav-data-processor / aggregator
       -> ultrav-core / ultrav-core-timewindow
       -> bidding-store / online-bidding
```

数据变更到广告池的链路是：

```text
Ads Platform / Marketplace DB / GDS / item & shop events
  -> paidads-gdshub
  -> indexjob.Job Kafka
  -> paidads-graph-indexer / paidads-indexer
  -> Vespa + AdsInfo(Valar)
  -> paidads-recall / ads-engine / bidding-store
```

| 服务 | 上游 | 下游 | 核心协议/数据 |
| --- | --- | --- | --- |
| `ads-engine` | Search/Discovery/Content BFF | recall、Valar、bidding-store、online-bidding、FSE、AB | SPEX API0-API4、Graph Engine DAG |
| `paidads-recall` | ads-engine API0 / API4 | Vespa、Redis、OhMyEmb、Feature 服务 | Graph YAML、KNN/KV/keyword recall result |
| `online-bidding` | ads-engine API2/API4 | ads-engine response / deduction params | Rerank proto、`DeductionParam`、trace |
| `bidding-store` | ads-engine / online-bidding | Redis / local cache / Kafka CoefEvent | `CoefCacheKey`、`AdCoefInfo` |
| `ultrav-core` / `ultrav-core-timewindow` | tracking/report/posterior streams | Redis、Kafka、Hive | coef、`HyperXLog`、Databus Redis |
| `paidads-gdshub` | GDS/marketplace/ads platform Kafka | indexer Kafka | `indexjob.Job` |
| `paidads-graph-indexer` | `indexjob.Job` | Vespa、AdsInfo event、IndexLog | Decision/Collector/Sinker graph |
| `paidads-valar` / gateway | AdsInfo event / Redis | ads-engine、recall、bidding、data | `get_ads_info`、`get_ads_info_changes`、`full_load_ads_info` |
| `paidads-tracking` | FE HTTP / TMS Kafka | report、deduction、traffic Kafka | `ads.Tracking`、checksum、fraud、dedup |
| `paidads-report-ng` | tracking、order mart、translog、content OA | report_event、ads_order、unified_order_event | Redis history、attribution |
| `paidads-deduction` | tracking/TMS deduction topics | offline-deduction、status-check | `CPCEvent`、`CPMEvent`、`OCPMEvent` |
