## 3.1 Ads System Architecture Overview

For the ads/search/recommendation traffic architecture diagram, see [§1.3.1.1](../01.ads-overview/03.system-pipeline-modules.md#1311-广告链路架构图) - [§1.3.1.3](../01.ads-overview/03.system-pipeline-modules.md#1313-推荐流量架构图).

Additional architecture diagram: [Google Drawing](https://docs.google.com/drawings/d/1zeoE1ehhg31lO0Bz2WFCRg_-k6aYOr3kzt-nq3Fh9ko/edit).

### Graph Engine

The current Ads system uses Graph Engine's DAG model to orchestrate online requests, indexing, recall, and data processing. Graph Manager provides visualization and editing, Graph Config stores YAML configuration, and Graph Engine executes the DAG.

| Module | Link | Current Role |
| --- | --- | --- |
| Graph Manager | [Portal](https://graphmanager.shopee.io/) / [Repo](https://git.garena.com/shopee/deep/searchads/graph-manager) | Online tool for viewing, editing, and validating Ads DAGs; it reads graph-manager-conf, renders SVG/PNG through graph-engine tooling, and links to GitLab MR workflows. |
| Graph Config | [Repo](https://git.garena.com/shopee/deep/searchads/graph-manager-conf) | Ads DAG configuration repository that maintains opdef files, graph YAML files, and the config.yaml registry; it centrally maintains business domains, operator definitions, graph definitions, and the registry. |
| Graph Engine | [Repo](https://git.garena.com/shopee/deep/searchads/graph-engine) | Go DAG orchestration and execution library that abstracts Op, Node, Graph, and GraphEngine; services define graphs with YAML/JSON and implement custom Operators when needed. |
