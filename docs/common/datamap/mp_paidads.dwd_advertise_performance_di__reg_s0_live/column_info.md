# Columns: mp_paidads.dwd_advertise_performance_di__reg_s0_live

## Column Usage Notes

### Non-Additive Fields

This table is event-level (one row per event), so most metric columns have MAX value = 1 (e.g., `impression_cnt`, `click_cnt`, `order_cnt`, `broad_order_cnt`). They are additive at the event level via simple `SUM()`. No SUM(DISTINCT) pattern is needed for this table unlike aggregated tables.

However, be aware that events can have duplicate rows in certain edge cases (CPM deduction fix records). When precision is critical, use `deduct_unique_id` for deduplication.

### Common Filter Values

- `tz_type`: `'local'` (~100% of production queries)
- `grass_region`: Standard 8 regions `('ID','MY','PH','SG','TH','TW','VN','BR')`, plus US regions `('MX','AR','CL','CO')`
- `placement`: See Value Mappings above for groupings
- `pricing_type`: `9,10,14` (Live Ads), `18` (ROI3), `1,2` (CPC Manual), `3,4` (CPC Simple)
- Common existence filter: `click_cnt IS NOT NULL OR order_cnt IS NOT NULL OR broad_order_cnt IS NOT NULL`
- Revenue filter: `expenditure_amt_usd > 0`

### 查询频率分析

Top 20 高频查询字段可分为以下几类主题：

1. **分区键**（#1-3）：`grass_date`、`grass_region`、`tz_type` 作为分区列，几乎所有查询都会用到，L30D 查询量远超其他字段（79K-112K）。
2. **核心维度**（#4-5, #7-8, #10-11, #13, #19-20）：`entrance`、`placement`、`user_id`、`pricing_type`、`item_id`、`ads_id`、`shop_id`、`order_id`、`campaign_id` 是最常用的广告维度字段，用于按入口、版位、用户、商品、广告、店铺、订单和活动进行分组聚合。
3. **效果指标**（#6, #9, #12, #14-18）：`expenditure_amt_usd`、`impression_cnt`、`broad_order_cnt`、`click_cnt`、`broad_gmv_amt_local`、`order_cnt`、`expenditure_amt_local`、`ads_order_gmv_usd` 覆盖了广告投放的核心效果指标——花费、曝光、点击、订单和 GMV。

**使用模式**：典型查询以分区键过滤，按维度字段（ads_id、shop_id、entrance、placement 等）分组，对效果指标（花费、GMV、订单数、点击数）求和聚合，用于广告效果报表和 ROI 分析。

> MAX(column): MAX() aggregated values from grass_date=2026-03-25, grass_region=SG, tz_type=local (only NULL if ALL rows are NULL)
