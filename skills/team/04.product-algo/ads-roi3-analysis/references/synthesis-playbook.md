# 合成层 playbook（老板级总账：赚不赚/值不值/扩不扩）/Synthesis Playbook

老板级问题（中层"这季度哪个方向在创造利润"、VP"发券整体边际还赚不赚、白烧的钱多大"）不是单个格子，是**多实验摊到同口径的合成判断**。本 playbook 给半自动合成方法（设计蓝本 §2 合成层；v1 先半自动、不全自动）。压测中中层/VP/高阶 PM 共撞此缺口。

## 0. 合成四步

1. **分解**：父问题 → 子格子清单（哪几个实验/region/档的读数能拼出这个判断）。
2. **新鲜度过滤**：每个子读数标可信度等级（见 §1），数据不够的**显式标出**，不硬合。
3. **同口径对齐**：三实验摊到同一张表、同一 value 口径（见 §2），advv/broad_gmv 双口径并行。
4. **合成判断**：加权/聚合 + 冲突处理（见 §3）+ 一页纸输出（见 §4）。

## 1. 实验新鲜度 → 可信度等级（诚实的关键）

边际/打平结论需 trailing ≥14 天；新实验天数不够只能给方向信号。每个子读数按运行天数标等级：

| 运行满日天数 | 可信度 | 怎么用 |
|---|---|---|
| ≥14 天 | **坐实** | 边际/打平结论可下，带 CI |
| 7~13 天 | **方向信号** | 只说方向（涨/平/跌），不下坐实结论，标 CI 宽 |
| <7 天 / 未放量稳态 | **不足** | 仅作"已观测到"的现象，不进决策，显式标"数据不够、暂不知道" |

当前实测（2026-06）：预算转移有效窗 ~4 天、维度边际 ~4-6 天 → 多数子读数处"方向信号/不足"，合成时**必须把这点写在报告头**，别让老板把方向信号当坐实结论。

## 2. 三实验同口径对比表（模板）

把在跑的实验摊到一张表，同一 value 口径（advv 和 broad_gmv 各一版）：

| 实验方向 | 增量券成本 | 增量 value | 边际利润率 | 撞 guardrail? | 运行天数/可信度 |
|---|---|---|---|---|---|
| 预算转移（调强度系数） | … | … | … | … | ~4d / 方向信号 |
| 维度边际（品类/entrance 打平） | … | … | … | … | ~4-6d / 方向信号 |
| 全局 11 档 dose | … | … | … | … | 较长 / 坐实 |

- 增量用 DiD 净增量（见 experiment-analysis 的 did-net-incremental.md），不是裸 test−control。
- 边际用调整后边际（连乘 dose 二维交叉，marginal-method §7），不是全局平均糊弄。
- 标出哪个方向边际最高（该加码）、哪个已饱和（该收手，见 saturation-vs-dilution.md）。

## 3. 冲突处理（五分类，报冲突不硬合）

合成时若子结论打架，按类型显式处理（设计蓝本 §4.2）：
- **口径冲突**：advv 与 broad_gmv 方向反向 → **自动标红**该格子，两栏分别给，优先信 advv 并注明 broad_gmv 自然流量稀释风险。
- **证据层冲突**：品类 guardrail 法 vs 边际利润法方向相反 → 报冲突 + 给各自前提。
- **新鲜度冲突**：两侧数据时间窗不一致 → 对齐窗口或标注。
- **因果/关联冲突**：关联读数 vs 因果(DiD)估计相左 → 信因果。
- **叠加效应冲突**：多维系数相乘破坏预算中性（重复抑制）→ 单维分别评估。

## 4. 一页纸输出（VP/中层版）

1. **一句话结论**：整体净利润方向（正/负）+ 信心（坐实/方向信号）。
2. **同口径对比表**（§2）：三实验摊平，边际为重点。
3. **饱和地图**：按 region×档标出已进边际≤0 饱和区的，占当前券成本的百分比（"白烧的钱"多大）。
4. **实测闭环 vs 模型外推两栏**（VP 强制）：能站住的实测部分 / 模型外推部分分开；外推的标"高估风险"（MY 深档外推高估 9 倍的教训）。
5. **诚实标注**：数据不够/天数不足/口径反向的格子，显式写"这里我们其实不知道"，不硬下结论。
6. **动作**：加码一个方向 + 收手一个方向 + 下季度最该改的一件事。

数字打头、大白话、不堆术语（report-skeleton 老板版规则）。
